# Security Policy

## Supported Versions
We maintain the latest `frontend/` application. Please report issues against the active main branch.

## Reporting a Vulnerability
- Email: security@example.com (replace with your address)
- Do not open public GitHub issues for security problems.
- Provide a clear description, impact, and steps to reproduce.
- We will acknowledge receipt within 72 hours and provide a remediation timeline when possible.

## Disclosure
We follow responsible disclosure. Please give us reasonable time to remediate before public disclosure.
