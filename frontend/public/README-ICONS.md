# Missing Icon Files

You need to add these favicon files to the `/public` folder:

## Required Files:
1. **favicon.ico** - Standard favicon (256x256)
2. **favicon-16x16.png** - Small favicon (16x16)
3. **apple-touch-icon.png** - iOS home screen icon (180x180)
4. **og-image.png** - Open Graph image for social sharing (1200x630)

## How to Generate:
1. Use [favicon.io](https://favicon.io/) to generate all sizes
2. Or use [RealFaviconGenerator](https://realfavicongenerator.net/)
3. Upload your logo/icon and download the generated package

## Quick Fix (Temporary):
For now, the missing favicons will show 404 errors in console but won't break the site.
You can ignore these until you have your actual branding assets ready.
