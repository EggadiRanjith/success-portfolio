# Success Portfolio

Ultra‑premium, mobile‑first frontend portfolio built with Next.js, TypeScript, Tailwind, Framer Motion, and GSAP.

## Quick Start
```bash
cd success-portfolio/frontend
npm install
npm run dev
```

## Features
- Theme system (light/dark) without FOUC
- Glassmorphism utilities
- Narrative route transitions
- Matrix Mode (press M)
- Accessibility: prefers‑reduced‑motion

## Structure
```
success-portfolio/
  frontend/  # Next.js app
```
